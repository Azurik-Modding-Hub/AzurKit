# Developer log

Every change to **AzurKit** in detail, for contributors: what it does, the step and decisions it comes from and how
it was checked. What players notice is in README's Features, in plain words. The format is loosely based on
[Keep a Changelog](https://keepachangelog.com).

## [Unreleased]

Each change's entry is its own file in [`devlog/`](devlog/), never a line here:
`devlog/<section>/<step>-<slug>.md`, its section `added`, `changed`, `removed` or `fixed`, its name in lower-case
letters, digits, dots and hyphens, the file one Markdown bullet. A release joins them into a section below.
