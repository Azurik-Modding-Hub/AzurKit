- **A UV that isn't finite is refused by name when a texture is baked** (Step 4.37h): `paint._raster` cast a NaN UV to an integer, which Apple Silicon and the browser's wasm make 0 (an unnamed `ValueError` followed) and x86-64 makes the least int64 (nothing drawn), so the twin's answer depended on the CPU (D1009) and `test_the_side_module_under_pyodide_gives_the_twins_answer` failed on Linux, Windows and the Intel Mac. It now refuses such a triangle by name before any cast, on every CPU; a variant's glTF, the vanilla bodies and the island and atlas ops already refuse a UV that isn't finite before it gets there.
