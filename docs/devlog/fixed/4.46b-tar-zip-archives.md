- **The leak guard reads inside a tar or zip archive** (Step 4.46b, audit pass 2's H3): it read only a file's name and its bytes at fixed offsets, so a tar, a `.tar.gz` or a zip holding an EEPROM dump, an xemu disk, a snapshot, a key or an image part passed; now each file such an archive holds (a tar also in a gzip file, a zip also in a gzip file or another archive, three wrappings deep) is checked by its name in the archive and its bytes, up to a damaged spot. 7z, rar, zstd, xz and bzip2 archives are still checked only as files.
