- **A seat's window no longer waits behind every queued gate for the suite lock** (Step 4.47a, D1222): macOS hands a released flock to its first waiter in the order they blocked, so a window ticket waited past three hours while the gates queued before it ran one after another. A queued gate now tries the lock every 0.5 s and takes a free one only on its turn: the oldest live queued run, which yields to a waiting window when a gate took the lock last (`lock.turn` and `lock.window` beside the lock), so a gate and a window seat alternate.
