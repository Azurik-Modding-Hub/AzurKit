- A PNG is inflated with bounds (`core/inflate.py`): one past 4096x4096 is refused before a byte inflates, and image data longer than its header's rows (a zlib bomb: 64 MiB of file to about 66 GB) is refused after at most one byte more, in the textures' reader and in a glTF folder's read-back (Step S1, D992 SEC-5).
- A content manifest is checked in time linear in its size: its requires are walked once with a done set and a stack of its own, so an 80-entry lattice that took months is checked at once and a 5,000-deep chain is named, not a `RecursionError`; a manifest holds at most 1,000 entries and 10,000 files, a JSON nested too deep or a requires that isn't a list of ids is refused by name (Step S1, D992 SEC-6).
- An Install checks each file as it lands and writes it into the entry's `.part-<id>/` folder, so it holds one file at a time (4 files of 5 MiB: 5.4 MB held, from 21 MB), and a refused file removes the parts and writes nothing; an entry's files, and an Install's (the entry and those it requires), are at most 256 MiB (Step S1, D992 SEC-9; the hosts' fetch reading at most a file's size is 4.3m's).
