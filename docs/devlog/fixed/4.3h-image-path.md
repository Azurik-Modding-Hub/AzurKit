- A transparently compressed image (`ditto --hfsCompression`, afsctool) saves its own bytes again: the clone a Save makes keeps the input's compression flag and drops only the others, so the file on disk is the build whose sha256 it reports (Step 4.3h).
- The site writes what this browser keeps installed into its engine file by file, each only where its path is one a manifest may list and installed.json holds its sha256: a planted `../` key, which once wrote over the engine's own Python, is left out with a line in the console and never written (SEC-2, Step 4.3h).
- The site tells two images apart by a sample of their bytes too (the first and last MiB, the XBE's header among them), not only by name, size and time: a look-alike picked after the vanilla image is checked as itself and never read from the other's kept blocks, and a fresh check of the image is never answered by an older one (SEC-13, Step 4.3h).
