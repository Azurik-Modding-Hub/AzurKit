- **Every test run keeps only its failed tests' temporary folders** (Step 4.5v2, tests only): pytest's defaults kept every test's `tmp_path` for its last 3 sessions, so the gate's site tests' downloads (built images) piled up, one 8-worker gate's 44 GB. `pyproject.toml` now sets `tmp_path_retention_policy = "failed"` and `tmp_path_retention_count = 1`: a passing test's folder goes as it ends, a passing session's whole folder at its end, and of the failed sessions' (their failed tests' and their module- and session-wide folders) only the newest's stays, where the defaults kept three. CI's vanilla tier drops its own `-o tmp_path_retention_policy=failed`, now the default; `tests/test_contracts.py` pins both.
