- **What a mods file changes, before a build: the Data tab's Changes and `azurkit diff`** (Step 4.6i, P23; Modkit's `diff`): the Data tab's seventh view, Changes (`sdk.data`'s view `changes`, `tools.data._changes`), lists each cell the page's edits change (a loaded mods file's too), table by table in the tabs' order, its vanilla value beside the cell itself (editable, marked ● and ⚠ as elsewhere), then the byte edits a mods file brought, each its file, offset and size; with no edits it says so. `sdk.mods_diff({"text"})` gives each edit of a mods file (a preset, a build's mods file, a link or Modkit's mod file) as a build makes it of the vanilla config.xbr (`tools.data.preview`): a cell by the file's own names with its vanilla and new values, one that changes nothing, a byte edit of a level left to the build, or why a build refuses it, beside the rest, with a Modkit mod's name and description; `azurkit diff MODS...` prints them numbered (`~`, `=`, `?`, `ERROR`) with the counts and exits 1 when one would fail the build. On Modkit's own diff input its lines match Modkit f482ea041's `diff` edit for edit (same cells, values, refusal and exit), and AzurKit lists the `xbr_edits` byte edit too. 1,000 changed cells take about 15 ms in CPython; `tests/_perf.py`'s A94 and S80 time the view after A46's and S39's load.
