- **The movie and audio tools** (Step 4.6l; D950, Modkit's `azurik-mod movies` and `audio` verbs, P65 and P66): `python -m devkit movies info` reads a Bink movie's header (a folder's as a table), `movies frames` its per-frame offset table (`--info`, the track layout detected) or its frames as PNGs into a new folder by ffmpeg, naming ffmpeg when it is missing or fails; `python -m devkit audio dump` writes every wave entry of an XBR (fx.xbr, a voice bank), a streamed one's samples from its sdsr, with a WAV for each the game decodes and a manifest naming each from the archive's own table. The manifest gives each entry's first 32 bytes as a sha256[:12], where Modkit's held them in hex. On the USA image both verbs give Modkit's output: the 14 movies' table and AdreniumLogo's frame table, and fx.xbr's 700 and english.xbr's 234 waves file for file. `devkit/movies/README.md` and `devkit/audio/README.md` are the reference, `tests/test_devkit_media.py` the tests (Modkit's movie and audio tests, merged into five).
