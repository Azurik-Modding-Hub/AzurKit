- **`azurkit entity diff`: two config.xbr entities side by side** (Step 4.6i, P59; Modkit's `entity diff`): `sdk.entity_diff({"a", "b", "all"?})` (`tools.data.compare`) joins two entities' cells (each its column of that exact name, the last when repeated; an empty cell is none) by property in each table that holds either, sorted: what they hold differently, what only one holds and, with `all`, what they hold alike, and the tables only one is in; an entity no table holds is refused by name, either side (AZ-145). `azurkit entity diff A B [--all] [--json]` prints them by table (`~`, `-`, `+`, `=`) or as JSON, from the config.xbr AzurKit ships. Its JSON rows equal Modkit f482ea041's `entity diff --json --all` on five pairs (garret4/air_elemental, catalisk/catalisk_baby, golem/lord_golem, norm_1/norm_2, garret4/garret4), with AzurKit's words for the types (number, text) and `table` for Modkit's `section`. Modkit's `--config` and `--iso` aren't kept: AzurKit reads only the vanilla config.xbr, both releases' file.
